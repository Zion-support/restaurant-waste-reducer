## Features
- Computer-vision-ready waste logging by station, shift and dish
- Purchasing optimization from waste + sales mix data
- Menu engineering matrix (stars, plowhorses, puzzles, dogs)
- COGS and margin alerts with supplier price drift detection
- Sustainability reporting (CO2e avoided, donation tracking)
